## Reading order for someone new to this

1. **Ontology** — why a graph, and what the classes are.
2. **Explorer** — see it, click around for five minutes.
3. **Schema** — how it is actually built.
4. **Proof of Value** — what it would take to do it for real on one slice.

## Two things that block progress

**Currency.** All of this is built from the Wavsys standing review of
18 May 2026. The San Angelo downgrade, the stalled ACX upgrade and the open
Juniper case were live threads then. Confirm what still holds before committing
scope — if the anomalies have been resolved, the model is unaffected but the
demo examples need replacing.

**Identity-resolution precedence.** Which system wins per property when
inventory, the NMS, GIS and ticketing disagree about the same device. That is a
CTTC decision, not a modelling one, and nothing loads until it is made.
